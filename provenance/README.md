# Source attribution

`source_files.json` identifies the source and packaged SHA-256 hash of each
adapted algorithm and calibration file. Source paths refer to the originating
research archive; runtime paths are configured through `configs/project.json`.

The numerical implementation is checked against its source in
[algorithm_parity.json](../verification/algorithm_parity.json). The remaining
validation records are described in [validation](../verification/README.md).
